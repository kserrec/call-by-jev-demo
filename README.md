# Call-by-Jev demo

Play at https://kserrec.github.io/call-by-jev-demo/

This repository contains only the built static website. The implementation and
project documentation are maintained in a separate private repository.

Jev is not connected. STLC subset and Polymorphic identity each reduce locally.
Mixed choice displays the legal options but does not choose between them.
There are no provider requests, API credentials, analytics, or persistence.
